Radio

Every enabled station below is a live audio item in the Radio channel (Home, My Media), in this order. It plays in Jellyfin's music player on the web; Jellyfin Desktop and the Android and iOS apps are being verified (docs/SPIKES.md). Users need access to the channel: Dashboard > Users > Access > Channels.

Stations

Only MP3 streams. Paste the stream itself, not a playlist (.m3u, .pls); press Test to check it and measure its format. Removing or disabling a station deletes its item when you save: playlist entries for it are lost for good. Favourites come back if the same station (same id) returns within 90 days.

Options

Android Auto asks Jellyfin for a redirect to the station and then fetches it itself. Tick this when that fails, for example with a server reached over http: the server then streams it instead. The web, Android and iOS apps always go through the server; Jellyfin Desktop and Chromecast always fetch the station directly.

Hide the channel from

For example a living-room Android TV account: that app cannot play channel audio. This only hides the channel; do not tick an administrator you also use in the dashboard (Radio would then be missing from every user's Access tab).
